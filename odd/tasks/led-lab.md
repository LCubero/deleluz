# LED lab: 2-day test bench and capability analysis

Build a simple but fully working Web Bluetooth test app for the LEDDMX-03 controller, use it to explore and document
everything the strip and controller can do (limits, places, improvements), before deciding the phone app scope.

## Specs

- S1: "primero quiero poder probar toido lo que podemos hacer explorar y documentar, para asi saber que vamos a poner el el app para celular, necesito una version simple pero bien funcional para probar y ver que le agregamos, tengo unos 2 dias para eso" — a simple, fully working test app; decision: web page using Web Bluetooth (Chrome on PC with the USB adapter, and Android Chrome); priority: the current LEDDMX-03 controller.
- S2: "posibilidad de hacer que funcionen con arduino o esp32 o raspberry, para poder manajarlas por red , wifi, bluetooth, usb. varias en una raspberry pi 3b+ como cerebro, o en boards de fpv betaflight led. uart/ puerrto led strip." — analyze (documented research; no such hardware available yet, only the PC USB Bluetooth adapter).
- S3: "quiero que el usuario pueda  crear sus modos o pintar el led strip led por led o sector por sector, facil comodo y con buena interfaz." — custom modes and per-LED / per-sector painting in the lab, sending only what the controller proves it supports; the rest is preview.
- S4: "ver y probar si podemos modificar el como funciona el chip y cosas del led, como para mejorar la conexion del bluetooth, mas modos, o mejorar los modos, etc etc." — chip investigation; user rule: "pregutnandome ahi vamos llegando hasta donde podamos y yo te deje" (ask before each riskier step).
- S5: "hay que saber que se puyede hacer como donde, hasta cuanto, limitaciones, posibilidades de mejora, etc etc. antes que todo tener todo bien documentado y analizado sin asumir. se puede investigar, probar, usar el adb, bluetooth de la pc, etc etc" — evidence-tagged capability document (CONFIRMED / CAPTURED / CANDIDATE / UNKNOWN).

- S6: "deben de existir modos navidad, fijos y con movimiento." and "modos que me gustaria contar, policia, rasta verde, amarillo y rojo, sirena, flashing." — preset modes in the lab built only from CONFIRMED frames (whole-strip color, brightness, power); anything needing different colors on different LEDs at the same time is impossible with the stock controller until a per-pixel frame is found, and must be said so in the UI; also look for native effects that already show these patterns.
- S7: Lab usability for round 2: one-tap worked / no change / unexpected per traffic log line, and an automatic send-rate test.
